# turbinebmw

Apps for [omarchy-mobile](https://github.com/turbineBMW/omarchy-mobile) phones,
published as the assets of the release `repo`; this repository holds nothing
else. Add it in the phone's Store (Sources > Add source):

    https://github.com/turbineBMW/turbinebmw-apps/releases/download/repo

Its apps' ids start with `dev.turbinebmw.`, and everything is signed with

    AE235CE9BD10D38684C81D19378C147A731F0C3A

Made with omarchy-publish (docs/app-repos.md#publishing-a-repo).
